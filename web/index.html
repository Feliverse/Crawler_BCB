Crawler BCB

Explorador de resultados del JSON

La estructura nueva del JSON es un árbol jerárquico. Selecciona una categoría a la izquierda para explorar sus ramas y documentos.

Cómo usar

  1. 1. El panel izquierdo lista las categorías raíz del árbol.
  2. 2. Haz clic en una categoría para ver su contenido jerárquico.
  3. 3. Usa Buscar para filtrar por texto y el selector de fecha para priorizar documentos con metadatos.

Nuevo JSON

El visor entiende una raíz como ESTADISTICAS y recorre niveles como categoría, rama y documento sin depender de nombres fijos.

Consejo

Si la página no carga el JSON automáticamente, abre el archivo desde el botón de carga manual o ejecuta un servidor local en la carpeta web/.
